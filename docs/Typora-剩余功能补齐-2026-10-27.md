# Typora 功能差距：后续补齐记录

本记录接续 [2026-10-26 功能核对](Typora-功能差距核对-2026-10-26.md)，区分已实现能力、验证范围和仍未完成的功能。Typora 的公开参考包括 [代码块](https://support.typora.io/Code-Fences/)、[复制与粘贴](https://support.typora.io/Copy-and-Paste/) 和 [搜索](https://support.typora.io/Search/)；目录排除及代码块会话覆盖是本项目提供的实现方式，不表示官方文档规定了相同的配置或行为。

| 对照项 | 本轮实现 | 边界 |
| --- | --- | --- |
| E14 代码块 | 可逐块覆盖行号和折行，默认语言应用范围可配置，可启用 Shift+Tab 自动缩进 | 逐块覆盖只保存到当前文档会话，不写 Markdown；关闭重开后重置 |
| R11 复制 | 实时预览可复制 Markdown 或语义纯文本、净化后的 HTML 和受限 RTF；提供不使用主题及只复制 Markdown 的入口 | RTF 不嵌入图片或活动对象，不保证外部应用的版式一致；大选区退化为纯文本 |
| W07 文件管理 | 工作区内支持移动、重命名目录及会话内撤销，协调多窗口文档、草稿及资源路径；空且身份未变的新建目录可撤销 | 历史重启后不保留；跨文件系统移动和系统回收站恢复未实现。macOS 已验证原生目录移动，Windows 实机待验；外部程序在系统调用前替换路径仍可能造成竞争，详见[目录操作](目录文件操作.md) |
| W09 工作区搜索 | 支持逗号分隔的目录名或相对路径排除，支持 `*` 与 `?`；结果和当前文档高亮同步排除 | 最多 20 项、输入最长 256 字符；不支持跨文件批量替换 |
| X05 上次导出 | 保存文档的上次成功导出目标和外观设置跨重启保留；覆盖目标前重新确认，配置过期或历史被外部修改时停止相应操作 | 按路径记录，文档移动后旧记录不迁移；未保存文档只在当前窗口保留。记录不包含正文、可执行程序、参数或模板，详见[上次导出记录](导出历史.md) |
| X14 语言 | 支持中文和英文预览，包括偏好设置、菜单、常用对话框、编辑器和已登记固定错误；跨窗口和重启保留 | 英文覆盖尚不完整，动态错误和系统对话框可能仍为中文；不翻译用户内容。自动更新未实现，详见[界面语言](界面语言.md) |

更多编辑与复制细节见 [代码块与复制](代码块与复制.md)。

## 仍需后续实现或平台验收

- macOS 系统版本历史：临时目录实验证实系统 JXA 可调用 `NSFileCoordinator` 创建并读取版本，但应用尚未集成版本列表、恢复或原生版本浏览器。接入保存事务前，需要验证现有原子保存、冲突检测、元数据与失败语义，不能把实验当成已交付功能。[Apple NSFileVersion](https://developer.apple.com/documentation/foundation/nsfileversion)
- 应用自动更新：现有帮助菜单只打开发行页，尚无可验证的版本比较、可信更新签名、下载安装和回滚机制；不能将发行页入口视为自动更新。
- 英文预览仍需补齐未覆盖的界面、动态错误和格式化；系统原生文案由操作系统决定。
- 目录操作的 Windows 原生桥及跨平台实际行为尚需 Windows 实机测试；macOS 测试不证明 Windows 行为。
- 上轮差距表中的其他部分实现、未实现和平台待验项目仍需逐项核对；本记录不声称已达到 Typora 全部功能或全部平台一致性。

## 本轮验证范围

类型检查、构建及 457 项单元测试通过。macOS Electron 桌面用例覆盖代码块显示与撤销、剪贴板格式、跨窗口目录操作、导出历史、目录搜索排除及语言切换。两次完整桌面回归均有 137 项通过、1 项测试清理超时、2 项跳过；已定位并修复测试夹具退出竞态，修复后定向重复 60 项通过，完整回归尚待用户在方便时重跑，详见[故障记录](fault-reviews/2026-10-27-electron-test-cleanup-timeout.md)。Windows 打包和实机测试本轮未执行。
