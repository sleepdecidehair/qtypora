## 数据与进程保护

- Markdown 原文保持唯一事实来源；格式、图片、表格和浮动工具栏以明确原文范围进行修改，选区及撤销/重做由编辑器事务维护。
- 文件移动配合所有窗口的文档路径锁更新文档与草稿路径；过期路径保存请求拒绝执行。移动及撤销不覆盖已存在的目标文件。
- 保存延续原字节/BOM/换行策略和版本检查；导入创建未保存草稿，不将输入文件作为保存目标。
- 导出校验文档版本及生成计划对应的偏好版本，禁止覆盖任一窗口已打开的源文档；转换完成后再次检查目标文件身份/版本，在与 Markdown 保存共用的每目标串行队列中原子写入。成功后才记录可复用的导出设置。
- 自定义程序来自用户配置，文档元数据不能授权执行。参数数组调用、不经过 Shell，转换输出/日志有大小和时间限制；终止后等待进程关闭再清理临时目录。Windows 子进程树终止实现需要 Windows 实机补验。
- 文档链接只能在当前会话已授权路径内访问；可执行文件、脚本、快捷方式、宏文档和任意协议不通过附件入口打开。缺失 Markdown 先确认，再用独占创建防止覆盖并发写入。
- 预设 JSON 仅允许版本 1 的内建格式和页面设置，256 KB / 20 项预算；不能携带可执行程序、Pandoc 路径或模板。导入先预览同名冲突，默认保留现有项；主进程在保存锁内按最新配置合并，保护其它窗口刚加入的同名项。导出按目标串行、检查并发修改和所有窗口源文件后原子写入。
- 固定目录必须来自已有授权或此前记录；偏好更新不能自行扩大文件访问范围。第三方声明通过应用内只读窗口加载，支持 ASAR 资源路径，禁止文档脚本和导航。
- HTML/SVG/MathML 仍经过净化；导出窗口关闭文档 JavaScript。RE2 搜索不使用可灾难回溯的主进程原生正则。

## 已知限制与外部前提

| 范围 | 当前限制 |
| --- | --- |
| 文件移动与撤销 | 只移动普通文件，限同一工作区/文件系统。当前窗口保留最近 20 次普通文件移动、重命名、新建和副本记录，重启后不保留；目录移动/目录操作撤销与原生回收站恢复未实现。撤销创建/副本校验文件身份和内容，已打开的未保存缓冲仍保留。原子保存或外部替换改变文件身份后会拒绝撤销，不会猜测并覆盖 |
| 文件列表/搜索 | 列表索引预算 200 目录、5000 文件、20000 条目；目录搜索深度 24、扫描 10000 条目、结果 1000 条。超大文档/目录无法声称全量结果。RE2 查询最长 256 字符、不支持环视和反向引用 |
| 统计与拼写 | 统计单位与阅读速度已持久化，统计口径未与 Typora 每个样例核准等值。临时忽略只屏蔽当前窗口的拼写建议，刷新/关闭清空，不修改个人字典；Electron 原生红色波浪线可能保留。系统/运行时词典效果仍按平台验证 |
| 主题与快捷键 | CSS 只限文章普通规则，不加载外部 URL/@import；不是完整 Typora 主题兼容层。应用菜单可自定义，原生和 CodeMirror 固定编辑键仍保留 |
| 导出配置 | 已提供最多 20 个内建格式具名预设、重命名及版本 1 JSON 导入导出；上次导出记录只在当前窗口文档生命周期内。纸张与四边边距可配置，PDF Info 元数据完整映射和各种阅读器书签表现未完成 |
| 图像与可移植性 | 长图最大高度 16000 像素。远程图片可在导出时安全下载（最多 20 张、单张 10 MB、合计 32 MB，私网/本机拒绝）；音视频/iframe/字体和全部图表的跨格式保真按实际目标阅读器核对 |
| Pandoc | 用户需另行安装，应用没有捆绑。已提供十五种输出与常见输入入口，包含 PPTX、Beamer .tex、GFM、CommonMark 和纯文本；不提供任意方言或直接编译 Beamer PDF。复杂排版、文献/引用、受密码保护文档和全部版本组合没有完整保真承诺 |
| 导入包资源 | DOCX/ODT/EPUB 包须满足安全展开预算；内嵌图片最多 20 张、单张 10 MB、总计 32 MB。外部路径不自动授权，坏图片/不支持格式会返回错误 |
| 自定义工具 | 导出程序、模板及上传器必须由用户安装配置；不自动安装依赖。不执行 Shell 字符串；Windows 批处理脚本不是可直接调用的原生可执行程序 |
| 发行和许可证 | “查看更新与发行记录”只打开既有公开发布页，没有自动版本比较或下载/安装。项目自身许可证未确定；第三方声明已打包，正式分发前仍需许可及字体审阅 |

| 需求 | 仍需的决定或环境 |
