## 交付与平台工作

- 正式安装包、签名、分发等待用户之后授权，本轮仅构建代码并运行 debug。
- macOS 是后续平台计划，目前没有 Mac 真机、构建、签名、公证和菜单适配验收。
- 当前 Electron 44 的 Windows 基线为 x64 开发验证；ARM64 尚未验证，x86 不受该运行时支持，不能承诺已有 x86 安装包。
- Typora 1.14 的同版本像素基准、所有主题截图、Narrator、多 DPI、性能预算和完整验收样例仍需完成。
- 本机现有 Typora 资源显示 0.11.18，不用其旧版资源冒充 1.14 真机验证；本次官方模式结论主要来自当前官方文档与发行说明。
