## 根因与证据

Mermaid 的 SVG 含 `foreignObject` HTML 标签和 SVG 内部样式。
原 SVG 净化删除了标签承载的 HTML 及渲染所需样式，导致文字消失、填充颜色回退为黑色。
仅设置 `flowchart.htmlLabels=false` 未覆盖新图形渲染路径；本机抓取的原始 SVG 仍含 HTML 标签。
此外，预览继承了 CodeMirror 的 `white-space` 行为，HTML 内的排版换行被绘制为异常空白。

## 解决方案

在全局设置 `htmlLabels=false`。残余 `foreignObject` 转为纯 SVG text/tspan。
通过 CSSStyleSheet 解析样式，仅保留同一 SVG ID 范围内的绘图属性，过滤 at-rule、外部 URL
和执行相关写法。允许通过颜色及绘图属性白名单的标准 classDef/style，继续禁止脚本、外链、
嵌入对象、自定义初始化配置及点击回调；不再一概拒绝标准配色指令。
根据 viewBox 设置图表固有大小，预览正文采用 `white-space:normal`。

相关代码集中在 `src/renderer/editor/markdown.ts` 和 `editor.css`。

## 验证与预防

真实 Electron 用例验证“写作”“保存”两个中文节点可见，节点 fill 不是黑色，
公式、本地图片及任务列表同时显示。导出 HTML 包含净化后的 SVG。
浅色与深色截图已人工查看。用户文章的 8 张 Mermaid 图和 3 张表格已通过严格渲染复核；
标准填充配色和带外部 URL 的非法样式另有真实桌面回归，最终结果见《开发验证记录》。

图表净化测试必须同时检查安全性与可见语义。保留 SVG 元素数量不能证明标签或颜色正确；
第三方渲染库升级后，需再次检查实际输出的标签承载方式。
