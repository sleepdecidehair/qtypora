# 故障复盘：构建依赖版本不兼容

| 字段 | 内容 |
| --- | --- |
| 日期 | 2026-09-30 |
| 发现 | 首次工程依赖安装 |
| 严重程度 | P2，阻断本地初始化 |
| 影响 | 新建工程，尚未涉及用户文档 |
| 提交和 Issue | 当前项目未初始化 Git，无关联提交 |

## 问题描述

首次 `npm install --no-audit --no-fund` 返回 ERESOLVE。`package.json` 同时选择了
Vite 8.3.1 与 electron-vite 5.0.0，后者声明的 peer 范围为 Vite 5、6、7。

```text
peer vite@"^5.0.0 || ^6.0.0 || ^7.0.0" from electron-vite@5.0.0
Found: vite@8.3.1
```

## 原因与证据

安装失败首先指向依赖树，随后通过 `npm view electron-vite@5 peerDependencies --json`
确认范围；继续核对 React 插件及 Vitest 的 peer 范围，排除应用源码导致失败。
根因是初始化时逐个选取新版本，遗漏组合之间的兼容交集。安装器在任何应用代码运行前发现问题。

## 解决方案

将 `package.json` 中 Vite 固定为 7.3.6，React 插件固定为 5.2.0，保留 electron-vite 5.0.0
和兼容 Vite 7 的 Vitest 5.0.2。重新安装通过，生成 `package-lock.json`。
没有使用 force 或 legacy-peer-deps 掩盖不兼容关系。

## 预防措施

- 更新构建工具时，先核对 bundler、Electron 插件、React 插件和测试工具的 peer 范围。
- 通过 lockfile 固定已安装组合；后续验收包含类型检查、编译及真实窗口启动。
- 本机 Electron 下载需通过环境已有代理，使用 `ELECTRON_GET_USE_PROXY=1`；不将代理地址写进项目。

## 经验

工程依赖必须按兼容组合选择，不能只比较单个包的版本新旧。
