## 问题描述

空段落输入井号，标记立即不可见，行和光标采用标题字号。用户要求井号保持普通文本，输入分隔空格才转换标题；删除空格恢复标记和字号。

这是显示和输入逻辑问题，无异常日志。原文仍保留井号，但视觉隐藏妨碍继续输入和判断状态。

## 根本原因分析

1. 井号消失、光标变大指向标题装饰及标记隐藏。
2. `inlinePreviewSpans` 为语法树中的 ATX 标题直接添加标题行样式并隐藏 HeaderMark。
3. 解析器将裸井号识别为空标题；合法语法不等于用户已经完成输入确认。
4. 原逻辑缺少标记后分隔空白条件，所以首个井号即改变形态。
5. 测试覆盖完成标题，未覆盖前缀逐字输入和删空格的反向过程，未提前捕获边界。

直接原因是无条件使用标题装饰。设计遗漏是把文档语法有效性和交互确认时机合为一项。

位置：[live-inline.ts](../../src/renderer/editor/live-inline.ts:24)。

## 解决方案

取得起始 HeaderMark，仅在其后为空格或制表符时添加标题装饰。裸井号继续显示普通文本，Setext 保留原规则。

```ts
const openingMark = node.node.getChild('HeaderMark')
if (node.name.startsWith('ATX') && (!openingMark || !/^[ \t]/.test(state.doc.sliceString(openingMark.to, openingMark.to + 1)))) return
```

修复只控制即时预览，不改 Markdown 原文，不影响源码模式。
