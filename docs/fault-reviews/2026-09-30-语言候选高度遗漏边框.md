# 故障复盘：语言候选高度遗漏边框

## 基本信息

2026-09-30；Codex 视觉检查发现；P3；影响新语言候选弹窗外观，无正文或保存数据影响，无 Issue、PR 或提交。

## 问题与证据

输入 `py` 后只有 Python 一个候选，但截图出现滚动条。加入实际 DOM 检查后，`scrollHeight - clientHeight` 为 1，证明内容发生轻微溢出。

## 根因

[弹窗布局](../../src/renderer/editor/code-language-suggestions.ts:58) 原先按行数乘 28 加 8 计算高度，只包含行高及上下内边距；CSS 使用 border-box，并有上下边框，实际可用内容高度因此不足。根因是脚本复制部分 CSS 尺寸却遗漏盒模型边框。初次行为检查覆盖选择和保存，没有检查单行候选是否溢出，视觉检查才发现。

## 修复与验证

改为读取实际候选行高、上下内边距、上下边框，求和后向上取整，再限制五行视区及窗口可用空间。保留滚动能力，避免通过隐藏溢出来掩盖被裁切的候选。

[桌面测试](../../tests/code-fence.spec.ts:109) 检查单个候选的实际滚动尺寸差为 0。最终 17 项桌面检查通过，修复后的 `.debug/code-language-suggestions.png` 已查看，单行没有多余滚动条。

## 预防与经验

浮层按 CSS 实际盒模型计算尺寸，避免脚本重复硬编码样式值。验收分别检查单行无需滚动和多行可滚动，截图检查与键盘操作检查同时保留。
