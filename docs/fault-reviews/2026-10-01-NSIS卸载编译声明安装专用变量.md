# 故障复盘：NSIS 卸载编译不能声明未使用的安装专用变量

## 基本信息

| 字段 | 内容 |
| --- | --- |
| 日期 | 2026-10-01 |
| 发现人 | Codex 完整打包门禁 |
| 严重程度 | P2 一般 |
| 影响范围 | 新增图标宏的 NSIS 卸载程序构建；失败包未发布 |
| 关联提交 | 本地目录没有 Git 仓库 |

## 1. 问题描述

安装图标宏的独立集成测试通过，完整 electron-builder 构建却失败。日志 `20261001-132312-63b8e712/logs/pipeline.log` 明确记录：`warning 6001: Variable "qtyporaIconPath" not referenced or never set`，随后 `warning treated as error`。

## 2. 临时解决方案

保留失败构建和日志，成功产物指针保持原值，不分发暂存包。

## 3. 根因分析

`build/installer.nsh` 无条件声明 `qtyporaIconPath`，只有 `customInstall` 使用它。electron-builder 26 单独通过 `BUILD_UNINSTALLER` 构建卸载程序，该阶段不展开安装宏，因此变量没有引用。独立测试把安装和卸载放在同一 NSIS 脚本中，未覆盖这一分阶段编译方式。

## 4. 解决方案

把变量声明放入 `!ifndef BUILD_UNINSTALLER`，保留警告作为错误的门禁。完整统一脚本重新构建并验证安装和卸载程序；不只复用独立宏编译结果。

## 5. 预防措施

- 对安装阶段专用资源、变量和依赖标注编译边界。
- 独立集成测试通过后仍执行真实构建工具的所有阶段。
- 构建失败不更新 `release/latest.json`，保留诊断日志。

## 6. 经验总结

共用安装包含文件必须分别适用于安装与卸载编译环境。
