# 语法兼容与导出图片安全过滤复盘

日期：2026-10-26。范围：本轮 Typora 兼容补齐工作树；桌面最终结果由统一构建回归补记。

## 已确认根因与修复

- **内嵌图片在 HTML / Word 导出中丢失。** Markdown 图片首先输出到惰性的 `data-resource` 属性。DOMPurify 虽允许该属性名，仍以 URL 规则删除其中的 `data:` 值，导致 hydration 找不到资源；实际导出 HTML 仅剩无 `src` 的 `<img>`。只将 `data-resource` 声明为惰性 URL 属性，随后仍由 `isSafeResource` / `dataImageInfo` 校验光栅 MIME、魔数、base64 和 10 MB 上限。SVG data URI 与 JavaScript URL 不由此放行。
- **重复图片放大导出内存。** 原流程并发读取每次本地引用，且将原始 data URI 再复制到 `data-original-resource`，主进程 `replaceAll` 也未预检替换后的大小。现在按最终引用次数累计 24 MB HTML 预算；同一解析地址只读取/编码一次，串行编码前按二进制大小预估 base64，主进程预检后才构造替换结果，导出不附带重复原始资源属性。超限在写文件前失败。
- **公式超缓存上限反复解析。** 30 条、约 12 万源字符的公式可展开为约 348 万 MathML 字符；原来仅“不缓存”大结果，每个 live widget 又重算整文档，连续调用实测各约 3.7 秒。现在 MathML 与缓存采用统一 2 MB 上限，超限保留原文并明确提示；失败结果也按 key 有界缓存，文档间宏/编号仍隔离。
- **缓存 token 的渲染副作用。** 图片段落反复 `attrJoin` 导致 class 每次增长、widget HTML 判等持续失败，图片/公式节点在选区变化时不断重建。类名添加改为幂等；重复标题用递增索引去重，目录总展示量限制为 5000 项，Alerts 不再重复解析内联脚注。
- **局部编辑退出与标题输入回归。** 自动补全的默认最高优先级 Escape 抢占局部源码退出，改为显式较低优先级补全键位。新建标题的连续输入状态与点击已有标题分开记录；程序跳转可以保留标题预览。媒体标签位于普通段落的 HTML inline token 时，现也作为真实媒体块 hydration。

## 行为与风险边界

CommonMark 严格模式保留用户扩展开关，只在生效配置中禁用非标准扩展；预览与导出使用相同设置。Markdown 自动配对仅处理单字符输入，跳过 IME 合成、批量粘贴、代码、YAML、HTML、URL 等上下文；事务只修改明确原文范围，代码围栏、双美元块公式和列表触发保持可用。所有文件授权、SVG 结构校验、DOMPurify、IPC 限额和原子写入仍保留。

24 MB 是当前 IPC HTML 字符限额，图片 base64 为 ASCII。每图片仍遵守 10 MB 内嵌上限；原始 Markdown 文件的 16 MB 限额不变。完整 Typora 方言矩阵与实体输入法/跨平台矩阵不能由本轮单元测试代替。

- 指定官方 Pandoc 3.12.1 后，真实 DOCX / ODT / EPUB 图像往返与 HTML→DOCX→Markdown 图像用例通过。
- TypeScript 类型检查通过。
- `tests/markdown-features.spec.ts` 已补百万字节内嵌图片预览/导出及危险 URI 反例、空光标配对/撤销/可见光标、严格模式切换、超预算导出保留旧文件；`tests/settings-export-integration.spec.ts` 保留实际 UI HTML 图片 `src` 断言。上述新桌面用例等待统一构建后的最终回归结果。
