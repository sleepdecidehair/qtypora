# 故障复盘：Data URI 可绕过阅读预览预算

## 基本信息

2026-11-01；P1 渲染性能与内存风险；发现于多 Agent 代码审查；关联修复提交 `dd9ab38`。

## 问题与根因

预览预算为了允许内嵌图片而对 data URI 做了例外，并通过整篇正则扫描估算；超大 base64 文本因此既增加扫描成本，又可能进入 Markdown/HTML 渲染链。根因是以内容类别豁免资源预算，而不是先对唯一事实来源——原始 Markdown 长度——建立硬门禁。

相关位置：`src/renderer/editor/preview-budget.ts:3-8`、`ReadingView.tsx:78-83`。

## 解决方案

统一按原始文档字符数执行 200,000 字符硬限制，不再对 data URI 特判，也不在超限内容上运行全文正则或 Markdown 解析；小型 data URI 仍按正常内容预览。

## 验证与预防

`preview-budget.test.ts` 覆盖边界、小 data URI 和超大 data URI。资源预算的豁免必须证明不会扩大 CPU/内存复杂度；无法证明时应在解析前统一拒绝，而不是解析后补救。
