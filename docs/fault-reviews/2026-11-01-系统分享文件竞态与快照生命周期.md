# 故障复盘：系统分享存在文件竞态与快照生命周期缺口

## 基本信息

2026-11-01；P1 文件一致性与隐私风险；发现于多 Agent 代码审查；关联修复提交 `dd9ab38`。

## 问题与根因

原实现把用户文档原路径直接交给 macOS ShareMenu。校验完成后到分享服务实际读取之间，原文件仍可被替换，形成 TOCTOU；改为临时副本后，如果仅依赖进程内定时器，又会在面板仍打开时提前删除，或在崩溃后永久遗留完整文档。根因是把“校验时的字节快照”“原文件路径”和“分享面板生命周期”当成同一对象，且没有跨进程可验证的所有权。

相关位置：`src/main/native-share.ts:12-132`、`src/main/index.ts:773-780`、`:838-839`。

## 解决方案

分享前通过无符号链接跟随的受限读取取得稳定字节并核对版本，再写入 0700 目录和 0600 文件。目录名包含 PID 与随机 token，marker 同时校验格式、PID、token 和 macOS 进程出生标识；启动只清理原进程已退出或同 PID 已被新进程复用且 marker 完整的目录。每个窗口只保留最新一次分享，新分享先关闭旧面板并回收旧快照；窗口关闭和 `will-quit` 对精确跟踪目录同步清理，目录创建后立即进入追踪，覆盖在途退出。

## 验证与预防

`src/main/native-share.test.ts` 覆盖原文件替换、符号链接、活动面板保留、退出清理、死进程/活进程/无 marker 清扫和同窗口重复分享。后续修改临时文件功能时，必须同时审查字节身份、外部消费者完成时机、崩溃恢复和多实例隔离，不能只加固定 TTL。
