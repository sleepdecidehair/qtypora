# 故障复盘：非大纲模式仍重复解析全文并扫描当前行

## 基本信息

2026-11-01；P2 编辑交互性能问题；发现于多 Agent 代码审查；关联修复提交 `dd9ab38`。

## 问题与根因

侧边栏即使不显示大纲仍延迟解析完整 Markdown；App 每次渲染又通过截取光标前全文并 split 计算行号。大文档输入和移动光标会重复产生 O(n) 工作。根因是派生状态放在 React 渲染路径，并且没有按功能模式关闭不需要的计算。

相关位置：`src/renderer/App.tsx:550`、`components/Sidebar.tsx`、`editor/MarkdownEditor.tsx:255-386`。

## 解决方案

只有 outline 模式才延迟解析标题；当前行由 CodeMirror 的 `lineAt(selection.head)` 在文档或选区事务变化时上报，App 只保存整数状态，避免复制和分割全文。

## 验证与预防

真实 Electron 工作区/大纲用例验证行号、点击定位、源码不变和文件移动。编辑器高频路径中的派生数据应优先使用编辑器索引与增量事务，并在隐藏功能时完全停止计算。
