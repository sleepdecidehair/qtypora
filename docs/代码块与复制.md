# 代码块显示和复制

参考 [Typora Code Fences](https://support.typora.io/Code-Fences/) 与 [Copy and Paste](https://support.typora.io/Copy-and-Paste/)。

## 代码块显示

“偏好设置 → Markdown 与代码块”中的行号、自动折行仍为所有代码块的默认值。实时预览中，代码块右下角的“代码块显示”可以单独选择当前块的行号、折行或“跟随全局”。这是 QTypora 的会话显示设置：不写入 Markdown，不影响导出，不进入文本撤销历史。当前文档切换源码/实时预览及文档间切换时会保留；关闭并重新打开文档、重启应用或整块替换后重置。多个代码块可以各自设置，选择“跟随全局”恢复相应默认值。

“默认语言应用方式”可选 Markdown 输入与菜单、仅 Markdown 输入、仅菜单及快捷键。已填写的语言不会被默认值覆盖。打开“Shift+Tab 自动缩进代码”后，在代码块内使用 Shift+Tab 按当前语言的编辑器语法规则格式化当前行或选中行；单次修改作为独立事务，可以撤销。输入法组合中、跨代码块选区和只读状态不会触发这项编辑。语言服务没有可用的缩进规则时不改原文。

## 复制

实时预览中 Ctrl/Cmd+C 和右键“复制”同时提供 Markdown 原文或语义纯文本、HTML 和受限制的 RTF。偏好设置中的“复制时纯文本使用 Markdown 原文”决定纯文本格式；默认开启以保持原有习惯，HTML 和 RTF 仍提供格式。Ctrl/Cmd+Shift+C 或右键“复制为 Markdown”只复制原文。源码模式的普通复制保留纯文本原文。

右键“复制时不使用主题”生成不携带编辑器主题的语义 HTML 和基础格式 RTF；普通富文本复制包含当前文字、字体与字号等基本主题样式。RTF 支持文字、粗斜体、删除线、下划线、标题、列表、表格文本及图片替代文字；HTML 保留经过净化的链接与其它受支持的标签。RTF 不嵌入图片、图表、活动对象或可执行数据，不保证与 Word、Pages 等应用的版式完全一致。超过 200,000 字符的选区退化为复制 Markdown 纯文本，避免富文本解析放大；未修改编辑器或磁盘内容。剪切的右键操作只有剪贴板写入成功且目标文档未变化时才删除选区。

RTF 格式由 Markdown 渲染后经过净化的片段生成，用于外部剪贴板输出；从不根据 HTML 重建或替换编辑器中的 Markdown 源文。主进程只允许固定的纯文本、HTML 与受限 RTF 格式；拒绝 RTF 对象、文件、活动字段、超限和非法控制词。
