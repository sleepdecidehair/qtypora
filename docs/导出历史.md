# 上次导出记录

保存过的 Markdown 文档在成功导出后，会记住本地最近一次的输出格式、目标文件和页面外观设置。关闭应用并重新打开同一文件后，仍可从文件菜单使用“使用上次导出设置…”，或确认后使用“导出并覆盖上次文件…”。取消选择和导出失败不会写入成功记录。

- 历史按源文档路径保存，最多 20 篇；未保存文档的记录只在当前窗口存在。文档移动或重命名后，旧路径的持久记录不会自动迁移。当前窗口仍可选择先前目标，覆盖前需再次确认；重启后新路径不会自动复用旧记录。
- 记录不包含文档正文、可执行文件、程序参数、模板或 Pandoc 路径。恢复自定义导出时，只会使用当前用户偏好中仍存在的同名配置；配置已经删除时会要求重新选择。
- 覆盖上次目标前仍会显示原生确认，导出不能覆盖任一窗口打开的源文件。其他导出改变历史而使正在渲染的计划过期时，本次操作会提示重试。
- 历史存于应用用户数据目录的 `export-history.json`，采用有界读取和原子写入。如果文件损坏或被外部程序改动，原文件会保留；导出已写入而历史写入失败时，界面会明确提示文件已导出。排查前请备份该文件，避免覆盖其它实例的修改。
