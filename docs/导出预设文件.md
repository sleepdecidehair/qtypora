# 导出预设文件

在“更多导出格式与设置”窗口使用“导入预设 JSON…”或“导出预设 JSON…”。文件包含内建导出格式、主题、纸张、页边距、页眉页脚、页码、大纲和长图宽度。它不包含 Pandoc 路径、自定义程序、参数或模板路径。

导入后先显示预览，列出新增名称和同名冲突。默认保留已有同名预设；选择覆盖后，必须点击“导入并覆盖同名预设”才更新配置。取消导入不修改配置。导入只保存预设列表，不执行文档导出，也不自动选择导入项作为当前配置。

提交时按主进程最新列表处理同名策略，因此另一个窗口在预览后新增的同名预设也受到保留策略保护。超过总计 20 项会拒绝整次合并，不部分导入。

重命名时先选中已有预设，修改“预设名称”，再点击“重命名所选预设”。已有同名目标会报错，原配置保留。保存当前设置仍使用“保存当前导出预设”。

JSON 文件格式版本为 1：

```json
{
  "kind": "qtypora-export-presets",
  "version": 1,
  "presets": [
    {
      "name": "打印 A4",
      "format": "pdf",
      "settings": {
        "pageSize": "A4",
        "pageWidthMm": 210,
        "pageHeightMm": 297,
        "landscape": false,
        "marginMm": 15,
        "separateMargins": false,
        "marginTopMm": 15,
        "marginBottomMm": 15,
        "marginLeftMm": 15,
        "marginRightMm": 15,
        "header": "",
        "footer": "",
        "pageNumbers": true,
        "outline": true,
        "imageWidth": 1000,
        "theme": "light"
      }
    }
  ]
}
```

文件必须是有效 UTF-8 JSON，最大 256 KB、最多 20 项。版本 1 要求完整字段，拒绝额外字段、未知版本、重复名称、无效尺寸和 `custom` 程序格式；不自动迁移旧版或其他产品格式。建议通过界面导出文件，而不是手工拼写配置。

导出使用原生保存窗口和原子写入；取消返回原界面。目标若为已打开文档、符号链接或写入期间发生外部变更，会拒绝覆盖。
