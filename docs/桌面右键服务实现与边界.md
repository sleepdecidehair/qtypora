# 桌面右键服务实现与边界

日期：2026-09-30。范围：`src/main/**`、`src/preload/**`；不启动、重载或操作用户正在运行的调试窗口，不打包。

## 官方依据

- [File Management](https://support.typora.io/File-Management/)：文件右键打开、新窗口、新建、副本、重命名、回收站、路径复制与资源管理器定位。官方的文件操作撤销需要独立的操作历史，本轮不显示没有真实实现的撤销文件操作。
- [Images](https://support.typora.io/Images/)：复制和移动后更新图片引用；删除图片涉及原文件，而单纯删除 Markdown 引用保留原图。因此本实现明确区分“移除图片引用”和“删除图片（原文件及引用）”。移动、重命名和删除原图均提醒图片可能被其他文章共用。
- [What's New 1.3](https://support.typora.io/What's-New-1.3/)：资源另存为和复制格式；资源格式保存通过真实本地写入实现，主进程不会伪造成功。
- [Table Editing](https://support.typora.io/Table-Editing/)、[Code Fences](https://support.typora.io/Code-Fences/)、[What's New 0.11](https://support.typora.io/What's-New-0.11/)：为编辑器的表格行列、代码工具和链接动作提供菜单入口；具体文本操作由编辑器模块执行。
- [Electron Menu](https://www.electronjs.org/docs/latest/api/menu)、[Electron Clipboard](https://www.electronjs.org/docs/latest/api/clipboard)：使用原生 `Menu.popup`、关闭回调和 `closePopup`，剪贴板按照 Electron 44 的异步 `ClipboardItem` API 实现。

## 真实实现

| 能力 | 主进程行为 | 失败或取消语义 |
| --- | --- | --- |
| 原生右键菜单 | 固定 kind/action 白名单与实际能力交集；正文格式、段落、复制方式和插入使用子菜单；每项 id 是 ContextMenuAction | 无可用操作或取消返回 null；替换旧 popup、原生关闭、窗口销毁均只完成一次 |
| 剪贴板 | 异步读纯文本；一次原子写入 text/plain 与可选 text/html | 拒绝错误类型、NUL 与超过 16 MB 的 UTF-8 内容；不打印剪贴板内容 |
| 文件副本 | 仅普通 Markdown/.txt 文件；COPYFILE_EXCL 下寻找“副本”“副本 (2)”等名称，保留原始字节 | 目录、非支持文件、过大文件拒绝；并发创建不覆盖同名文件 |
| 文件/目录新窗口 | 必须先通过调用窗口的目录授权；目录建立真实工作区与监听，bootstrap 返回目录条目 | 非 Markdown 普通文件、未授权路径拒绝 |
| 目录右键打开 | 指定路径必须已获当前窗口授权，重新读取目录并替换工作区 | 不将 renderer 提供的任意路径视为用户授权 |
| 图片复制/移动 | 同步完整文档快照；检查图片是当前文档实际引用、属于本窗口且位于授权目录；原生保存对话框选择新路径；返回可插入的新 src | 取消返回 null；目标已有文件拒绝；文档修改、关闭、路径变化或原图 SHA 变化则保护原图 |
| 图片删除 | 原生明确确认共享风险后移入回收站；返回 `{ source: null }` 供编辑器删除引用 | 取消为独立的 null 返回，绝不等价于成功删除 |
| 原图片另存为 | 复制原格式字节，保留原文件和当前引用 | 不执行格式转换或覆盖既有文件 |
| 生成资源另存为 | SVG 通过真实 XML 解析、元素/命名空间/属性与内部链接校验；PNG/JPEG 校验结构、尺寸、Base64，并由 Electron nativeImage 解码；原子写入文件 | 禁止脚本、foreignObject、外部 URL、DTD、实体声明、处理指令、错误格式、超限尺寸和危险目标；失败不改变文档 |

## 权限和并发

IPC 复用可信主 frame、sender、当前页面验证。preload 只增加固定方法，不暴露 ipcRenderer、Node 或任意文件读取接口。图片原文件操作额外验证实际 Markdown 引用，网络和 data URL 不能获得磁盘删除权限。每个源图片操作按路径串行，原生对话框后的 destructive 操作再次验证文档快照和原图 SHA。

新图片目标使用同目录临时文件写入、fsync 和独占硬链接发布，避免覆盖竞争目标。资源导出在允许用户原生选择覆盖后再次检查目标 SHA；符号链接和非普通资源目标拒绝。临时文件在失败时清理。

文件树变更操作维持当前工作区授权边界。位于工作区之外的已打开文档仅提供打开、新窗口、复制路径和定位操作，不承诺目录树的重命名、回收站或副本操作。

## 尚未实现的官方扩展

所有图片批量复制/移动、远程图片下载、视频资源、文件操作历史撤销、资源上传与同步不属于本轮实现；不显示空成功入口。数学 SVG/PNG/JPEG 生成须编辑器提供真实转换，本服务仅保存真实提交的有效资源，不将 MathML 改扩展名伪装 SVG。

独占原子新文件发布使用文件系统硬链接，已在本机 Windows 临时目录验证；不支持硬链接的目标卷会明确报 IO 错误。Mac 实际窗口、回收站、剪贴板与文件系统行为仍需后续目标系统验收。
