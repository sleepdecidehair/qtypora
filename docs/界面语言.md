# 界面语言

在“偏好设置 → 语言 / Language”中可选择简体中文或英文。默认使用简体中文；已有配置没有语言字段时也沿用中文。语言作为应用偏好保存，切换后会同步到其他窗口，并用于之后启动的窗口。英文目前标记为预览版，尚不能保证所有界面、动态错误和系统对话框均为英文。

应用自有的菜单、常用设置与对话框、帮助和诊断信息使用语言字典；编辑器和文件管理界面也逐步接入。切换语言不会翻译或改写用户的 Markdown、路径、文件名、词典内容、拼写建议或自定义预设名称。新建欢迎文档使用创建时的语言，已有文档和恢复草稿不会因此重写。原生系统提供的文件选择器及其系统文案由操作系统决定。

## 开发约定

- 固定界面文案在 `src/shared/i18n.ts` 注册；React 组件通过 `useTranslation` 获取当前语言。编辑器内部的固定文案见 `src/renderer/editor/editor-i18n.ts`。
- 未登记的界面文案回退为中文原文；不要把用户内容传给界面翻译函数。
- `translateKnownError` 只转换 `src/shared/i18n-errors.ts` 中明确登记的完整固定错误，不替换消息片段。包含文件名、路径或其他动态数据的错误需要单独设计安全模板；目前此类消息可能保留中文。
- 新增 UI 或错误时应核对中文和英文、无障碍名称、异步操作及跨窗口语言变化。不得通过机器翻译服务发送用户内容。

`src/shared/i18n.test.ts` 和 `src/main/i18n.test.ts` 覆盖字典回退、固定错误边界、设置迁移与菜单中的用户文本保留。`tests/locale.spec.ts` 用隔离用户目录检查切换、窗口同步和重启；执行该桌面用例需要先按项目说明编译应用。
