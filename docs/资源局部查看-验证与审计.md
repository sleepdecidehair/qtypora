# 资源局部查看：验证与审计

日期：2026-09-30。范围：Windows 桌面资源查看器增量，标准风险前端交互。

## 用户可见行为

正文保留完整适配。普通图片右键“查看原图片”，图表/公式右键“查看资源”打开独立覆盖窗口。
滚轮以鼠标位置缩放，左键拖动平移；100% 为自然尺寸，最高 800%。
“适应窗口”或 0 恢复全图，“原始大小”或 1 查看原尺寸，+ / − 缩放，方向键平移，Esc 关闭。
Tab/Shift+Tab 循环焦点；加载失败给出提示并禁用缩放。
关闭保持文章源文、选区和滚动位置。查看期间隔离编辑器命令，原生窗口关闭继续保护草稿。

## 实现与检查范围

- `src/renderer/editor/ResourceViewer.tsx`：资源加载、测量、缩放/拖动、焦点、快捷键、监听器清理。

- `src/renderer/editor/editor.css`：查看器工具条、画布和既有主题变量；保留并行任务增加的代码块样式。
- `src/renderer/App.tsx`：查看器打开时拦截 Electron IPC 菜单命令，允许原生窗口关闭保护。
- `tests/resource-viewer.spec.ts`：4 项真实 Electron 验收；`resource-viewport.test.ts`：7 项几何单测。
- `tests/context-menu.spec.ts`：既有表格测试等待保存锁释放与撤销后源状态，再执行保存。

未改桌面接口、服务、资源解析和默认正文缩放。用户确认同目录有并行编辑器任务，相关改动保留。
